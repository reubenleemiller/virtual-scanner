Workflow

Built for stubborn legacy scan dialogs

Some classroom, testing, records, and office applications still expect a scanner source even when the document already exists as a file. Virtual Scanner gives those applications a familiar TWAIN source while keeping the files local on the Windows machine.

01

Install the matching build

Pick the installer that matches the TWAIN application architecture.

02

Add files to the inbox

Queue local PNG, JPG, TIFF, or PDF files using the inbox helper.

03

Scan from your app

Your TWAIN application receives the queued files as scanned pages.

Trust and transparency

Open source, reproducible releases, local files.

The source code, installer script, release workflow, privacy policy, and license are public. GitHub Actions builds the release files from that source, and each release can include SHA256 checksums so downloads can be verified.

# Privacy Policy

Virtual Scanner does not collect, transmit, sell, or share personal data.

The application runs locally on the user's Windows computer. Files selected for
scanning remain on the user's computer unless the user separately shares or
uploads them using other software.

Virtual Scanner may write local diagnostic logs to help troubleshoot
installation or scanning behavior. These logs remain on the user's computer and
are not transmitted by the application.

For questions about this policy, contact Reuben Miller.

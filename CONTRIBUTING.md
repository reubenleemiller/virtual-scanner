# Contributing

Thanks for helping improve Virtual Scanner.

## Development

1. Open an issue or pull request describing the change.
2. Keep changes focused and include build or test notes when possible.
3. Do not commit generated release artifacts unless the change specifically
   concerns packaging output.

## Licensing

By contributing to this repository, you agree that your contribution is licensed
under the MIT License in `LICENSE`.

Only submit work that you have the right to contribute. If a contribution
includes third-party code, images, icons, generated assets, or documentation,
include the required license notices and attribution in the pull request.

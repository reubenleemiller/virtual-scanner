# Security Policy

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately to Reuben Miller
before opening a public issue.

Include:

- The affected version or commit.
- Steps to reproduce the issue.
- Any relevant logs, screenshots, or sample files.
- Whether you believe the issue affects installer trust, file handling, or
  TWAIN data source loading.

This project is provided under the MIT License without warranty, but responsible
security reports are appreciated.
